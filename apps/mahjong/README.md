# NEXUS SYSTEM 02 · 港雀

麻将作为 NEXUS 同一域名下的 `/mahjong/` 页面运行。前端由 Vite 构建；NEXUS 的 Fastify 服务提供静态文件、`/mahjong/api/*` 账号接口和 `/mahjong/ws` 房间连接。

在 Render 上复用 NEXUS 的 `DATABASE_URL`，自动建立 `mahjong_accounts` 与 `mahjong_sessions` 表。无需新建数据库。现有本机麻将账号文件不会上传，线上账号需要重新注册；也不要将 `server/data/accounts.json` 加入 Git。

房间、未完成牌局与电脑操作计时器目前保存在服务进程内。Render 重新部署或实例重启会结束正在进行的房间；已注册账号与登录会话保存在 PostgreSQL。

## 手机 PWA 与完全无网开房

每台 iPhone / Android **先在有网时**打开 `https://nexus-2rwr.onrender.com/mahjong/`，登录一次，等页面加载完毕，再从浏览器菜单选择「加入主画面」/「安装应用」。账号资料会留在本机，游戏静态资源由 Service Worker 缓存。以后从主画面的「港雀」图标打开，即使没有 Internet，也能进入单机牌局和无网房间。首次注册、重设密码、修改资料以及线上房间仍须联网。

面对面无网牌局需要 2～4 台手机连接**同一热点**。房主在「朋友开房」选择「无网四人房」或「无网三人房」，点击「邀请朋友扫码」。朋友点「扫描房主的邀请二维码」，然后把自己手机上的回应二维码给房主扫描。每位朋友各做一次；空座可由电脑补位。房主开局后，所有摸牌、打牌、吃碰杠胡都由房主手机计算，再通过手机之间的 WebRTC DataChannel 同步。进行中的牌局不能加入新朋友；房主可取消本局，邀请新朋友，再重新开局。本局取消后分数不计。

二维码要双向交换，因为完全无网时，8 位房间码本身无法找到另一台手机。若相机不能使用，可复制／粘贴配对文字。扫码配对无需线上信令服务，也不用开启移动数据。两台手机必须一直保持热点连接，房主手机要保持 PWA 在前台且屏幕亮着；房主关闭应用或离开热点会结束无网房间，未完成牌局不会恢复。部分手机热点会阻止已连接设备互相通信；遇到连接失败可改由另一台手机开启热点并重新配对。iPhone 与 Android 混用时，务必先在实际要用的机型和热点上完成一次配对试玩。

安装与扫码要求浏览器安全环境：线上 HTTPS 页面或本机 `localhost`。从普通 `http://192.168.x.x` 地址打开网页时，手机浏览器可能拒绝 Service Worker 与相机权限。开发环境下无网配对也应先通过已安装的 HTTPS PWA 完成。
